# 知识库（maibot-plugin-knowledge-base）

> MaiBot 本地知识库插件：**知识数据随插件自带**，安装即用，运行时不依赖任何外部数据文件、无需联网。注册四个 Tool 供 LLM 按需调用。

- 插件 ID：`github.elmeir.knowledge-base`
- 宿主要求：MaiBot ≥ 1.2.4（maibot-plugin-sdk ≥ 2.8.0）
- 依赖：`jieba` ≥ 0.42.1（自动安装）
- 作者：[Elmeir](https://github.com/Elmeir) ｜ License：MIT
- 版本：见 [_manifest.json](_manifest.json) ｜ 变更见 [CHANGELOG.md](CHANGELOG.md)

## 功能

**萌娘百科**（`kb_data/*.index.json`，jieba + BM25）

- `search_knowledge`：检索萌娘百科知识库，主题含崩坏：星穹铁道 / 绝区零 / 原神 / 鸣潮 / 异环 / 明日方舟：终末地 / 萌战赛事等

**bangumi**（`kb_data/bangumi.db`，SQLite FTS5）

- `search_bangumi`：检索 Bangumi 资料库
- `get_bangumi_season`：季度新番列表（7/8/9 月归 7 月番，按追番人数排序）
- `browse_bangumi`：按标签/类型/年份/评分筛选作品（"最近的高分喜剧动画"）

检索特性：

- **离线检索**：jieba 分词 + BM25 打分，无需联网、不消耗 LLM 调用（约 2 ms/查询）；正文与小节标题分开打分、标题命中加权（"三月七 星魂"落到对应小节）；简称按字符近似兜底（"崩铁""星铁" ↔ "崩坏：星穹铁道"）；查询剥离疑问词，返回文本围绕命中位置开窗
- **智能问法**：角色名直查置顶该角色的"基本信息"（"艾莲·乔""三月七"）；"XX 有哪些角色"命中全量角色名单；"哪个角色可爱""你喜欢谁"命中萌点对比目录；萌战问法（萌王/燃王/人气/冠军）自动命中结果表，"今年/去年"自动换算年份
- **bangumi 资料库**：约 25 万条动画/漫画/游戏/音乐/三次元作品及角色、人物，含登场角色、制作人员（职位名映射）、关联作品（续作/改编关系）；简称缩写可召回（"京吹" →《吹响吧！上低音号》，"马娘" → "赛马娘"）
- **后台加载**：启动时后台任务加载全部索引，不阻塞宿主；加载完成前检索短暂等待（上限 15 秒）；数据缺失或单个索引文件损坏时温和降级（对应工具提示"未收录"，不影响其余功能），不作为错误上报

## 安装

1. 将本目录放入 MaiBot 的 `plugins/` 目录（或按你的插件安装方式放置）
2. 依赖会由宿主依赖管道自动安装（`jieba`）；手动安装可执行 `pip install -r requirements.txt`
3. 重启 MaiBot 即生效，无需任何配置

## 配置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `knowledge.top_k` | 4 | 每次检索默认返回的片段数 |
| `knowledge.max_chars` | 300 | 单个片段返回给模型的最大字符数 |

WebUI 插件页分 **知识库 / 调试** 两个页签：「调试」页含诊断日志开关与五张「组件信息」卡片（4 个工具的可见性 / 描述 / 参数 + `/kb_stats` 的描述 / 匹配模式，只读、随插件加载自动刷新）。

## 命令

| 命令 | 说明 |
|---|---|
| `/kb_stats` | 查看萌娘百科与 bangumi 的条目/片段数、构建时间与数据源日期 |

## 常见问题

- **日志显示"未找到内置知识数据"或工具回复"未收录知识数据"**：`kb_data/` 目录为空或缺失——数据随完整插件包分发，缺失说明安装不完整，请重新下载；缺失时插件其余功能不受影响，不会报错
- **检索结果不理想**：多词检索已内置覆盖加成，可尝试用更具体的词（角色名 + 关注点，如"三月七 星魂"）

## 数据来源

- 萌娘百科索引：内容来自[萌娘百科](https://zh.moegirl.org.cn/)，仅作本地离线检索用途
- bangumi 资料库：内容来自 [bangumi/Archive](https://github.com/bangumi/Archive) 每周导出的 wiki 数据
